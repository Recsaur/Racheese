# Racheese
Racheese is a game made for the Brackeys Game Jam 2026.2

Racheese is a game where you're supposed to get through puzzles, eat cheese, avoid moldy bad cheese and exit mazes in time. Do you think you can do it?
Play the game here: <a href="https://stelico.recsaur.hackclub.app/">https://stelico.recsaur.hackclub.app/</a>
